
# Rick and Morty App
### 🔖 About the app
A small **React Native app built with Expo** that explores the Rick and Morty universe. It fetches characters from an [public API](https://rickandmortyapi.com/), displays their details, and provides a simple interface to browse through the show's iconic cast. It serves as a practice project for mobile development, focusing on clean UI and API integration.

### ✨ Features
 - Fetches data from the Rick and Morty API
 - Displays character list with images, name, and status
 - Character detail page with extra information
 - Local “Saved Characters” section
 - Clean UI with a dark theme inspired by the show
 - Built with Expo, React Native, and modern component patterns

---

### 🚀 Running Locally (React Native + Expo)

#### Clone the project
```bash
git clone https://github.com/JooCrepaldi/rickAndMorty-API
```

#### Enter the project directory
```bash
cd rickAndMorty-API
```

#### Install dependencies
```bash
npm install
```

#### Start Expo
```bash
npx expo start
```
